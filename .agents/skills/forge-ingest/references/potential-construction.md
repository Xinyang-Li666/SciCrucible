# 反应型势函数构建文献专项提取规范

本规范由项目配置或用户明确指定时采用，适用于总结反应型机器学习势函数（包括Deep Potential, DP）的构建方法。它服务于势函数训练指导，不将文献的后续MD应用结果误当作建势细节。普通材料文献继续使用通用模板。

## 文献类型路由

| 文献类型 | 重点提取 | 不应推断 |
|---|---|---|
| 势函数构建 | 参考数据、构型生成、覆盖范围、采样和回标、训练及独立验证 | 未报告的训练细节或默认的DP适用性 |
| 势函数应用 | 训练势身份与引用来源、本文新增验证、模型适用条件 | 把引用论文的训练过程写成本文工作 |
| 反应采样/主动学习 | 候选构型来源、不确定性/偏差判据、增强采样及停止条件 | 把别的模型架构或采样参数直接移植到DP |
| 软件/方法 | 实际实现的功能、限制、输入标签要求和复现资源 | 把软件能力等同于具体化学体系已验证 |
| 实验或混合研究 | 仅提取可核实的计算建势部分及实验比较用途 | 用实验产物数据替代势函数的训练或验证证据 |

## 建势证据字段

逐篇记录以下信息；原文没有提供的字段可以空缺并注明原因，不为填表推测：

1. **模型身份与范围**：作者使用的架构/软件和版本；元素、组成、物种、电荷和自旋；气相、表面、凝聚相或跨相态；温度、密度和结构覆盖范围。
2. **量子参考与标签**：DFT或其他电子结构方法、泛函、赝势/基组及关键设置；训练数据中的能量、力、应力或其他标签；不同数据来源是否统一重算。
3. **初始构型来源**：平衡结构、扰动结构、AIMD、反应轨迹、过渡态/路径、自由基、产物、界面或人工构造结构；记录各自用途和数量单位。
4. **反应空间覆盖**：已验证的成键/断键、配位、电荷/自旋态、短程接近、过渡区域和竞争反应；区分“元素出现在数据中”与“相关反应被验证”。
5. **迭代选样**：探索模型或采样方法、模型间偏差/不确定度指标、触发阈值、候选去重、量子回标、失败回退和停止条件。完整记录单位和模型定义。
6. **训练与数据划分**：训练/验证/测试分割单位，是否避免相邻轨迹帧泄漏；损失项、权重变化、模型集合、截断/表示和重训练信息；只抄录作者实际报告的数值。
7. **独立检验**：能量、力、应力误差及数据分布；独立分子/组成/表面位点/反应通道；反应能、势垒、结构和动力学检验；跨温度或跨体系迁移测试。
8. **失效、适用边界与资源**：不稳定轨迹、未覆盖化学、元素外推、长程相互作用等限制；势文件、训练数据、代码和SI的可获取性。

## 三场景归纳矩阵

| 场景 | 提取重点 | 验证切分与外推问题 |
|---|---|---|
| 气相热裂解 | 前驱体、自由基、碎片、异构化、断键/成键与高能接近构型 | 按分子骨架、组成或反应通道留出；分别检验热化学量与反应路径 |
| 表面诱导裂解 | 表面模型及终止、吸附物、覆盖度、位点、表面重构和反应碎片 | 留出吸附位点、覆盖度或表面环境；检验表面与气相物种的交叉相互作用 |
| 凝聚态热解 | 链长、拓扑、交联、密度、局域断键、挥发产物、界面和陶瓷化结构 | 留出聚合物结构、组成或相态；避免只在相邻MD帧随机拆分造成泄漏 |

以上为本专题需对照文献回答的问题，不是无需验证的默认配方。三个场景可以共享量子参考的一致性、闭环选样和独立验证原则，但数据分布、边界条件与目标量必须分别论证。

## 来源定位和证据身份

每条关键结论都要对应PDF物理页码、印刷页码（若有）、章节、图/表/方程或SI位置。证据身份标记为：作者方法、作者结果、作者转引、本项目推断。区分原文使用DP、其他机器学习势和未确认架构；MTP、SSW-NN、GNN等不自动归类为DP。

任何建议写成“建议—文献依据—迁移理由—适用条件—需验证的风险”。训练集MAE、构型偏差、轨迹稳定性、反应能垒误差代表不同问题，不能互相替代，也不预设所有化学体系通用的合格阈值。只有获得对应SI/数据后才标注相应状态；未获得来源不写作“作者未报告”。

## 跨文献综合

先形成逐篇证据表，再按三个场景比较；每个综合判断至少区分直接DP证据、其他架构的方法借鉴和本项目推断。描述单篇案例时给出体系边界，不将烃类、含氧、含卤或盐类体系结果直接当作Si/N/H裂解势的验证。发生冲突时并列原文结论和差异条件，不强行合并成共识。
