# Agent 接入指南

先读 [发布状态](release-status.md) 与 [用户手册](../MANUAL.md)。本次仅公开安全独立工具和文档；进阶建库的完整实现仍待发布审计。

## 最小接入

1. 从仓库根目录工作，读取 [公共指令模板](../AGENTS.public.md)，再读取所用宿主的项目指令。项目规则优先于用户目录的旧版同名技能。
2. 读取 `.agents/skills/<技能>/SKILL.md` 中的项目技能；缺失时停止并说明。斜杠命令是宿主约定，其他 Agent 可直接读取技能后执行，不要求支持同名命令。
3. 先按发布状态确认脚本实际存在，再执行 CLI；参数以 `python -B scripts/<脚本>.py --help` 为准。不要把本地扩展文档当作已安装实现。

## 按任务进入

| 任务 | 入口 |
|---|---|
| PDF 摄入预检 | `scripts/ingest_prepare.py`，之后按 forge-ingest 编译知识 |
| 科研问题查本地证据 | `scripts/evidence_query.py probe --query "问题"`，采用候选 read_args 定向读取 |
| 写作/讨论/维护 | 对应 forge-writing / forge-think / forge-health 技能 |
| 新领域建库/继续批次 | 完整本地扩展可用时采用 forge-db；未发布实现不自动补装 |
| 下一批接管 | 先 `scripts/session_handoff.py check --handoff <路径>` |

主代理负责带证据审计、写死执行范围的计划与独立验收；子代理严格按计划执行，到停止条件即停。新批次使用全新会话，通过文件交接，不无限继承历史上下文。

模型调用、额度、门禁放宽及正式入库均受各自授权边界约束；常驻 grant 不是无限授权。只发送 pending，不发 held，失败不自动重试，冲突和证据不足不自动重问。输出文件摘要与定向字段，不倾倒完整数据库或长日志。

验证时区分预检通过、代码测试通过、来源复核通过与正式入库。引用真实文件、记录和原文定位，不编造数字或运行结果。私人 PDF、数据库和笔记不得发往外部插件。
