# /forge-think — 协作思考

> **SciCrucible 根目录**: `D:\科研\SciCrucible\` —— wiki/、brainstorming/ 以此为基准。

围绕一个材料科学问题展开探索性对话，帮助你理清思路。

## 本地证据按需调用

- 用户提出涉及本项目材料、方法、指标或既有结论的科研讨论时，默认以 `python scripts/evidence_query.py probe --query "<用户问题>"` 轻量探测 wiki 和 database；无需用户显式说“查库”。纯翻译、润色、格式编辑等任务跳过检索。
- 每段新科研讨论用 `python scripts/evidence_query.py probe --query "<用户问题>"` 轻量刷新目录并探测。有相关候选再定向 `expand`；database 只返回匹配记录和所需字段，不把整个 JSON 载入模型上下文。
- 连续追问复用上下文内仍然适用的已读证据；问题改变材料、指标、条件，来源已变化或现有证据不足时才重查。
- 引用库内结论时提供页面路径/行号或数据库记录定位，并指出适用条件。无匹配时说明“本地库未找到”，不外推为领域无证据。读取失败与无匹配必须区分。
- 不把本地 PDF、私有 wiki 或数据库发给外部插件；用户明确要求外部检索时只发送必要的公开检索问题/标识。

## 入口与失败回退（试点修正）

- 优先照抄候选的 `read_args`（参数数组，接在 `python scripts/evidence_query.py` 后），不要猜 `source_id`。数据库可用重复的 `--record-id <记录ID>` 选多条记录，再用 `--columns` 选字段；无需拼 JSON。`--where` 只接受精确匹配的 JSON 对象，不接受 SQL。数据库禁止无条件展开；检查 `matched_records`、`returned_records`、`truncated` 和 `truncation_reason`，截断不等于后面没有记录。
- 同名技能以本项目 `.agents/skills/` 下版本为准，不使用用户目录中的旧版同名技能替代；普通科研讨论也遵守项目 AGENTS.md。
- `probe` 已刷新目录，无需每次额外 `build`。明确查库的任务必须完成实际探测/读取后再回答，不能只回复“准备查询”。优先使用用户给出的完整记录 ID 或样品代号；不要读取脚本源码来猜数据层级。
- `status:error` 是读取/工具失败，不是无匹配。空候选只表示本次查找未命中；对明确本地对象可再用短关键词/准确 ID 查找一次。仍需后备搜索时用 `rg --no-ignore -n "<短关键词或ID>" wiki database`，严格限制在这两个允许根内，不从工作区根目录搜索，避免漏掉被 Git 忽略的数据库或读到评测参考。
- 相关候选出现后再定向读取；数据库用 `expand` 选择记录和字段。连续追问先复用已读原始证据；首轮尚未取到证据时不能把前次表态或“未找到”当证据复用。

## 流程

1. **理解问题**：复述用户提出的问题，确认理解正确
2. **按需搜索本地知识库**：当问题与项目相关时，轻量探测 `wiki/` 与 `database/`；不相关的讨论不检索
3. **判断状态**：
   - 如果问题在知识库中已有充分覆盖 → 直接回答，附引用
   - 如果问题部分覆盖但存在矛盾 → 指出矛盾，提出澄清问题
   - 如果问题是全新的 → 列出已有的相关基础，提出探索方向
4. **深度对话**：
   - 一次只问一个问题，帮你逐步深入
   - 指出文献中可能相关的线索
   - 挑战你的假设，提出反例
5. **总结**：对话结束时，提炼关键收获

## 边界条件

- **超出材料科学范围**：坦诚说明知识库的专业领域，但仍尽力用通用科学思维提供参考，标记 `[待验证]`
- **知识库无相关内容**：明确告知"知识库中暂无相关信息"，依赖一般知识回答时所有陈述加 `[待验证]`
- **问题过于模糊**：不急于展开，先问 1-2 个澄清问题缩小范围
- **对话陷入循环**：总结已达成的共识和待解决的问题，询问是否结束或换方向
- **sessions/ 目录缺失**：自动创建 `brainstorming/sessions/` 目录
- **用户中途想退出**：先做简短小结（3-5 条要点），再问保存选项

## 保存选项

对话结束时询问：
- "保存这次讨论到 brainstorming/sessions/？"
- "是否有新想法需要记录到 brainstorming/ideas/？"
- "是否需要对 wiki/ 中的页面做补充？"

## 内容质量标准

- 材料科学概念必须有准确定义，避免模糊表述
- 引用观点时注明出处（文献链接）
- 不确定的内容用 `[待验证]` 标记
- 叙述性内容至少 3-5 句，包含物理机制解释，避免纯提纲式罗列
