# /forge-think — 协作思考

> **SciCrucible 根目录**: `D:\科研\SciCrucible\` —— wiki/、brainstorming/ 以此为基准。

围绕一个材料科学问题展开探索性对话，帮助你理清思路。

## 流程

1. **理解问题**：复述用户提出的问题，确认理解正确
2. **搜索知识库**：在 `D:\科研\SciCrucible\wiki\` 中查找相关概念、文献和方法
3. **判断状态**：
   - 如果问题在知识库中已有充分覆盖 → 直接回答，附引用
   - 如果问题部分覆盖但存在矛盾 → 指出矛盾，提出澄清问题
   - 如果问题是全新的 → 列出已有的相关基础，提出探索方向
4. **深度对话**：
   - 一次只问一个问题，帮你逐步深入
   - 指出文献中可能相关的线索
   - 挑战你的假设，提出反例
5. **总结**：对话结束时，提炼关键收获

## 跨领域关联

鼓励跨材料体系的类比和关联：
- UHTC 氧化 ↔ 正极氧释放（共享 Ellingham、Wagner、Fick 物理框架）
- DFT 计算在两种体系中的方法论共享
- 在相关页面中显式标注跨领域关联

## 边界条件

- **超出材料科学范围**：坦诚说明知识库的专业领域，但仍尽力用通用科学思维提供参考，标记 `[待验证]`
- **知识库无相关内容**：明确告知"知识库中暂无相关信息"，依赖一般知识回答时所有陈述加 `[待验证]`
- **问题过于模糊**：不急于展开，先问 1-2 个澄清问题缩小范围
- **对话陷入循环**：总结已达成的共识和待解决的问题，询问是否结束或换方向
- **sessions/ 目录缺失**：自动创建 `brainstorming/sessions/` 目录
- **用户中途想退出**：先做简短小结（3-5 条要点），再问保存选项

## 保存选项

对话结束时询问：
- "保存这次讨论到 brainstorming/sessions/？"
- "是否有新想法需要记录到 brainstorming/ideas/？"
- "是否需要对 wiki/ 中的页面做补充？"

## 内容质量标准

- 材料科学概念必须有准确定义，避免模糊表述
- 引用观点时注明出处（文献链接）
- 不确定的内容用 `[待验证]` 标记
- 叙述性内容至少 3-5 句，包含物理机制解释，避免纯提纲式罗列
