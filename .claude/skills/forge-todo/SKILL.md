# /forge-todo — 待办管理

管理 `brainstorming/todos.md` 中的待办事项。

## 文件格式

brainstorming/todos.md 使用以下格式：

```markdown
# 待办事项

## 当前
- [ ] <描述> `关联:[[概念/项目]]` `优先级:高/中/低` `创建:YYYY-MM-DD`
- [x] <描述> `完成:YYYY-MM-DD`

## 已完成
- [x] <描述> `创建:YYYY-MM-DD` `完成:YYYY-MM-DD`
```

## 支持的操作

### 列出待办
用户输入 "待办" 或 "list" 时，展示所有未完成条目，按优先级排序。

### 添加待办
用户 "添加待办: <描述>" 时：
1. 识别描述中关联的概念/项目，添加 [[wiki-link]]
2. 默认优先级为中
3. 追加到待办列表

### 完成待办
用户 "完成 <描述>" 时：
1. 找到匹配条目
2. 标记 [x]，添加完成日期
3. 移到已完成区

### 清理已完成
用户 "清理待办" 时，将完成超过 30 天的条目归档（移到文件末尾的归档区）。
