# 新领域开库手册

适用于新增材料实验数据领域。用少量来源验证字段、证据和门禁，再扩大文献范围。复用项目的准备、暂存和导出流程，领域差异优先放在 profile、mapping、策略和布局模板中。钙钛矿试点以[热导率字段草案](../../brainstorming/sessions/2026-11-10-perovskite-kappa-db-field-draft.md)为口径。

## 1. 定义记录与领域 profile

| 项目 | 开工时确定的内容 | 钙钛矿热导率示例 |
|---|---|---|
| 范围与目标 | 材料体系、目标性质、研究温区、纳入和排除条件。明确作者比较句和方法论文如何使用。 | 无铅 (Ca,Sr,Ba)(Ti,Zr,Hf)O₃ 固溶体，PZT 排除。关注近 1500 K 低晶格 κ，300–1500 K 的高、低线膨胀方向分别保存。 |
| 性质口径 | 原单位、物理基准、实验或计算类型，以及直接测量、作者推算与入库复算的区别。 | 区分实验样品总热导、作者分离晶格热导与模拟晶格热导。平均 αₗ 保存温区，ΔL/L₀ 保存参考温度。 |
| 记录粒度 | 用样品、性质、事件和关键条件决定行身份。写清重复测量和条件变化如何分行。 | 样品 × 性质 × 温度或温区。同配方不同烧结条件分开编号，致密块体、多孔体和涂层分别标识。 |
| 组成与材料状态 | 原始化学式、名义与实测依据、归一化基准、位点或相、样品状态及处理历史。 | 保存 A/B 位分数、明确报告的空位和补偿。占位或缺陷未确认时留空。记录相组成、晶粒、密度、孔隙和烧结条件。 |
| 条件与证据 | 温度、时间、方法、方向、气氛、不确定度、次数、原文定位和缺失原因。区分关键与可空字段。 | 热导率、热扩散率和比热保留原值、温度与来源。区分体密度和理论密度、总孔隙和开口孔隙。 |
| 复算与派生 | 保存输入身份、转换关系与适用条件，规定复算何时有资格进入独立结果。 | κ 复算保留 D_th、ρ、C_p 三个输入及相互适配的温度和样品。注明各输入是实测、引用还是估算。 |

据此起草 `allowed_properties`、`field_rules`、`property_rules`、`critical_fields`、发布规则与视图，再配套 mapping。优先复用经过回归的约数、不确定度、成对次数、处理链原文、时长限定词及名义/实测组分语义。先测试字段落位、可空性和原样导出，领域试点通过后再声明覆盖。新增契约只进新版本。

## 2. 冻结来源并选择入口

1. 按 DOI、PDF SHA-256 和来源版本去重，区分原始研究、补充资料、综述和方法背景。冻结源 PDF、逐页解析文本、解析器版本和设置、页标记、区域与 scope，保存 PDF 和文本哈希。任何重新解析都生成新快照。
2. 在小样本统计可用数据分布。表格优先，正文补充，图列为独立入口。图占主导时报告图内缺口和预算，由用户决定是否解冻。钙钛矿的 κ 曲线多见于图，首版仅使用已启用入口内的证据。
3. 定位契约使用冻结文本逐字符切片及样品、条件、性质绑定。图若获批，要留物理页、区域、坐标轴、单位、曲线/系列和读数误差，保持作者报告值与读图值的来源区别。
4. 锚点唯一且版式稳定时用逐篇程序模板，保存适用版本、定位片段与 rule_hash。样品或条件需判读时走通用 admission，先隔离证据不足的值。两条路线共用来源身份和交付契约。

## 3. 金标准与首批验证

- 选 5–10 篇，覆盖表格、正文、可取得的图或暂缓图、无目标的负例，以及预期最难的单位或处理条件。正式覆盖评估先由人从原文标注，再跑扫描器。可用已知样本做调试，评估集和修规则样本分开。
- **金标准生产标准流程（每批 1 篇，2026-11-12 固化）**：① 起草——禁用扫描器，通读冻结原文全枚举观测（值/条件/定位/target 按政策 B′）；② 模型辅助核对——脚本按 locator 索引逐字引文 + ±5 行上下文窗口，`gpt-6.1-terra` 文本主核逐条判定 supported/conflict/insufficient；文本损坏或表格结构不清时 `gpt-6.1-sol` 视觉兜底（区域定位 + 证据页 PNG）；③ 人工只拍板 conflict/insufficient 条目，其余自动通过；④ 标记 reviewed 后跑后扫描对照，更新累计真实准召——该数字同时作为**校对与优化标准**（每版扫描器回归必过）。
- 冻结目标定义、每条原文定位和匹配口径。分入口计算精确率、召回率、定位正确率并列出非目标、误报、漏检和跨行碎片。由候选反向生成的金标准只能给出本集合召回上限。按基线、误差归因、最小修复、回归验收保留版本。
- 首批验证优先覆盖容易混淆的字段。钙钛矿按草案用 Zhang 2024 与 Yan 2026 验证近 1500 K 的组成对照，用 Xiang 多孔样品验证有效热导和组成效应分离。实际可取值的数量取决于冻结来源及已启用入口。方法论文先保留为背景。
- 先完成离线 dry-run 和逐字段对账，再按计划完成 **prepare → gate → stage**。交付样品/事件数、目标性质、缺失与隔离、定位回放和待授权清单。用户单独批准 commit 后，校验目录哈希和回执再提交及导出。主代理独立验收；执行者按协作板追加报告。

## 4. 两体系复用检查表

- [ ] 跨行数值和单位的引文分段保存。归并 ± 尾段时只抑制已消费的片段。相邻行同值匹配遵循事先冻结的引文口径。
- [ ] 双栏先识别栏位。同一物理行的两栏可能属于不同样品或段落。省略号只在原文能唯一展开时定位。
- [ ] 表头、单位和倍率按列保存，倍率缺号或出现 NUL 时保留原字符和定位，数值倍率留空。证实的倍率也保存原值及换算关系。
- [ ] 名义配方和实测组成分轨。粉末和成品、不同位点、相或样品状态不能只凭化学式合并。
- [ ] L-PBF 的消应力不填入固溶字段。确实无此处理时按领域 profile 留空并记原因。
- [ ] 不确定度、硬度约数、次数下界和时长约数分别记录。只缺一项的次数对触发校验，成对缺失按 profile 规则处理。
- [ ] 新语义或模板重放不得改变旧库绑定。保留旧配置、输入与基线，并验证已接纳记录读取和导出。
